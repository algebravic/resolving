#+Title: Counting Orbits in 0/1 matrices

* The Problem
Given positive integers, \(m, n\), let \(\mathcal{M}[m,n]\) be the set of all
\(m \times n\) 0/1 matrices. We have the following operations on 
\(\mathcal{M}[m,n]\):

1) Given a permutations \(\sigma \in S_m, \tau \in S_n\), map \(A \in
   \mathcal{M}[m,n]\) to \(A'\) where \(A'_{\sigma(i), \tau(j)} =
   A_{i,j}\), for \(i=1,\dots,m; j=1,\dots,n\). Call this element
   \(langle \sigma, \tau \rangle\).
2) Given \(a_i, b_j \in {0,1}\) for \(i=1,\dots,m; j=1,\dots,n\) map
   \(A\) to \(A'\) where \(A'_{i,j} = A_{i,j} + a_i + b_j \bmod 2\).

Calculate the number of orbits of \(G\), the group generated by the
above operations operating on \(\mathcal{M}[m,n]\).

* Approach

Use Burnside's theorem: If \(G\) is a group operating on the finite
set \(S\), the number of orbits is
\[ \frac{1}{|G|} \sum_{g \in G} |S^g|,\]

where \(|S^g|\) is the number of fixed points of the element \(g\)
operating on \(S\).

Each element \(g = \langle \sigma, \tau, a, b\rangle\).

We can analyze this by first looking at the orbits of \(\langle
\sigma, \tau \rangle\) acting on coordinates.
