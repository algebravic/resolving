The Problem
===========

For \(m,n\) positive integers we consider the set \(S\) of all \(m
\times n\) matrices with entries in \(\{0,1\}\). We have the following
actions on \(S\):

1) An arbitrary permutation of the rows.
2) An arbitrary permutation of the columns.
3) For any subset of the columns, we complement all of them, where
complementation means mapping 0 to 1 and 1 to 0.
4) For any subset of the rows we complement all of them.

Let \(G\) denote the group generated by all these operations.

I want an efficient algorithm to calculate the exact number of orbits
under these operations. By efficient, I mean as close to polynomial in
\(m\) and \(n\) as possible. This should make use of the Schreier-Sims
coset table decomposition.

As a second, refined, question, suppose that \(B\) is a subset of
\(S\) consisting of all the matrices with prescribed row sums. That
is, given \(r_1,r_2,\dots,r_m\), \(B\) consists of all matrices whose
\(i\)-th row sums to \(r_i\) for \(i=1,\dots,m\). Give an efficient
program which calculates the number of orbits obtained by \(G\) acting
on \(B\).

I want to be able to make these calculations in a reasonable time for
values of \(n\) through 16, where \(m\) is always less than \(n\).
